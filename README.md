# 🎧 Adaptive Listening Pro (수능 영어 듣기 맞춤 학습 시스템)

> 고등학교 단위학교 정규/상시 영어 듣기평가 및 초개인화 오답 클리닉 웹 애플리케이션  
> **🌐 서비스 바로가기 (GitHub Pages)**: [https://googyosoo.github.io/adaptive-listening-pro/](https://googyosoo.github.io/adaptive-listening-pro/)

---

## 📌 주요 핵심 기능

### 1. ⏱️ 실전 수능형 평가 모드 (Exam Mode)
- **실전 3단계 연속 방송 시퀀스**:
  - `[1단계]` 한국어 발문 안내방송 (`ko-KR` 음성 합성 모드)
  - `[2단계]` 수능 오리지널 딩동댕 시그널 차임벨 울림 (Web Audio API 주파수 무지연 합성)
  - `[3단계]` 원어민 실전 담화/대화 본문 (미국식/영국식 악센트 교차 재생)
- **실전 청취 제한**: 문항당 최대 2회 청취 제한 및 타이머 카운트다운.
- **수능 17대 표준 유형 규격화**: 11~14번 간접 말하기 유형 시 실제 수능과 동일하게 **영어 5지선다 선택지** 자동 분기.
- **지연 제로 사전 기출 세트(Exam Bank)**: 1회, 2회, 간접말하기 고난도 특훈 세트 내장 (네트워크 지연 없이 0.1초 즉시 응시).

### 2. 🎙️ AI 정밀 발음 코칭 & 롤플레잉 회화 (오답 클리닉)
- **발음 전반 4대 영역 종합 진단 피드백**:
  1. **정확도(Accuracy)**: 개별 음소 조음 완성도 및 일치율(%), 누락/오류 단어 정밀 진단
  2. **유창성 및 청킹(Fluency & Chunking)**: 의미 단위 끊어 읽기 호흡 및 발화 템포 코칭
  3. **연음 및 강세(Linking & Stress)**: 단어 간 연결 소리(Flap-t, 자음-모음 연음) 및 내용어 강세 조언
  4. **억양 및 리듬(Intonation)**: 서술어 하강조 및 문장 멜로디 조절 조언
- **1:1 대화형 롤플레잉(Role-Playing)**: 남/여 역할을 선택하여 AI 원어민과 실시간 턴테이킹 회화 훈련.
- **하이브리드 엔진**: Gemini 2.5 Flash API 연동 코칭 + API 미등록/네트워크 장애 시에도 100% 작동하는 자체 스마트 음운학 진단 엔진 탑재.

### 3. 👨‍🏫 교사 관리자 센터 (Teacher Dashboard)
- **비밀번호 인증 로그인** (`1234`)
- **실시간 학급 응시 현황 테이블**: 학년/반/번호/이름 다차원 필터링 및 취약 문항 정답률 즉시 파악.
- **성적표 엑셀(CSV, UTF-8 BOM) 다운로드**: 한글 깨짐 없는 원클릭 성적표 출력.
- **2022 개정 교육과정 기준 NEIS 과세특 초안 자동 생성**: 학생 누적 응시 데이터 및 발음/딕테이션 학습 태도를 반영한 500자(1500B) 학교생활기록부 세특 초안 원클릭 산출.

4. 시험 완료 후 상세 리뷰에서 1:1 쉐도잉 발음 평가 및 롤플레잉 회화를 진행합니다.
